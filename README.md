# **캡스톤 디자인2**  
**코멘토(Co-Mento) - AI 기반 코딩 테스트 플랫폼**

<br/>

## 프로젝트 개요  

코멘토는 알고리즘 문제 풀이와 AI 리뷰를 결합한 코딩 테스트 플랫폼입니다.  
사용자는 문제를 풀고 AI로부터 풀이 리뷰를 받아 코드의 개선점을 확인할 수 있습니다.  
학습 효율을 높이고, 문제 해결력을 키우는 차별화된 코딩 학습 경험을 제공합니다.

<br/>

---

## 기능 소개

### 1. 사용자 인증
- 일반 로그인 외에 소셜 로그인(네이버 로그인) 연결
- 회원가입 및 로그인 시 유효성 검사 기능 제공

### 2. 문제 목록
- 알고리즘 문제를 알고리즘별, 난이도별, 성공 여부별로 분류하여 제공
- 문제 유형별 필터링 및 검색 기능 제공
- 비슷한 문제를 묶어 문제집 형태로 제공
- 메인페이지에서 문제집 별 진행도 제공

### 3. 문제 풀이
- C, C++, Python, Java 등 10개의 프로그래밍 언어 지원
- 사용자 경험을 고려한 코드 에디터 제공
- 제출 후 채점 로딩 화면 표시

### 4. AI 리뷰
- 문제 풀이 후 AI 기반 리뷰 기능 제공
- GPT API를 활용하여 사용자 코드에 대해 프롬프트 기반의 결과 제공
- 코드의 효율성 및 가독성 개선 포인트 제시

### 5. 사용자 프로필 관리
- 즐겨찾는 문제, 맞힌 문제, 틀린 문제 등 개인화된 기록 제공
- 제출한 문제 목록 및 AI 리뷰 기록 저장

### 6. 랭킹
- 사용자 랭킹 시스템 제공
- 경험치 표시로 성취감 제공

## **설치 및 실행 방법**

### 1. **프로젝트 클론**  
```bash
git clone https://github.com/Heesu01/co-mento.git
```

### 2. **의존성 설치**  
```bash
yarn install
```

### 3. **환경 변수 설정**  
`.env` 파일에 아래 내용을 추가합니다:
```
HTTPS=true
SSL_CRT_FILE=./server.cert
SSL_KEY_FILE=./server.pem
REACT_APP_BASE_URL=https://api.likelion-crossover-team2.com
```

### 4. **개발 서버 실행**  
```bash
yarn start:ssl
```

## **컨벤션**

### 브랜치 네이밍  
| Prefix   | Description           |
|----------|-----------------------|
| `main`   | 배포용 브랜치          |
| `develop`| 개발 중간 작업 브랜치 |
| `feature`   | 기능 추가 브랜치      |
| `api`   | api 연결 브랜치      |

### 커밋 메시지  
| Prefix   | Description           |
|----------|-----------------------|
| `feat`   | 새로운 기능 추가       |
| `fix`    | 기능,UI 수정             |
| `hotfix`  | 긴급수정     |
| `docs`   | 문서 추가/수정         |
| `refactor` | 코드 리팩터링         |
